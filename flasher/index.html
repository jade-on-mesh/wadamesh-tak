What is MediaMesh?

MediaMesh gives photos and voice their own lane. Text, adverts and acknowledgements stay on the main mesh, while the photos and voice clips that MeshCore Open TAK and Wadamesh TAK send go out on a second, faster LoRa profile (radio2). A device with MediaMesh on still hears the main mesh, so it keeps working with every repeater around it.

  • Standalone radioFlash Wadamesh TAK, then turn MediaMesh on under Settings › Radio › MediaMesh Settings.
  • With a phoneFlash a Keymind Cascade companion and pair it with the MeshCore Open TAK app.
  • RepeaterFlash Keymind Cascade and set up radio2. Every MediaMesh repeater carries photos and voice farther.

Install

Download the file, then drop it here or choose it. The page checks it before flashing.
Or install by drag-and-drop instead
  1. Download the .uf2 file.
  2. Plug the device in over USB and double-press its reset button quickly. A USB drive appears (its name depends on the board, such as NRF52BOOT, RAK4631 or the board's own name).
  3. Drag the .uf2 onto that drive. The drive disappears and the device restarts on its own when it's done. A "disk not ejected" warning is normal.

Ready

This board isn't flashed through a browser. Download the file and install it with the board's own tool (UF2 drag-and-drop for RP2040 boards, STM32CubeProgrammer for STM32WL).

      If it doesn't work
      
    
        
  • No port shows up: try another cable (many are charge-only) and another USB port. On Windows, a CH340 or CP210x driver may be needed for some boards.
    • 
        
  • nRF52 board doesn't answer in step 2: double-press its reset button so it shows up as a USB drive, then press 2. Install firmware and pick its port. Or use drag-and-drop instead.
    • 
        
  • "Failed to connect" or it times out: put the board in download mode (see the tip above), then press Install again.
    • 
        
  • Port is busy: close the MeshCore app, Arduino, PlatformIO or any other tab that has the device open.
    • 
        
  • Screen stays black after flashing: unplug the board and plug it back in.
    • 
        
  • DX-LR30 doesn't answer: enter the bootloader again right before pressing Install (hold BOOT0, press and release RESET, release BOOT0; the LED stays on). The page talks to it at 57600 baud, the only speed this board's bootloader answers at.
    • 
        
  • Already running the firmware? Wadamesh TAK updates itself from Settings › About › Install update. Keymind Cascade repeaters with OTAFix can update over Wi-Fi or LoRa; see the setup guide linked in step 2.
